# TokenSpin

TokenSpin is a high-performance, real-time data processing hub that leverages auto-scaling and load balancing engine capabilities.

With TokenSpin, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/TokenSpin.git`
2. `cd TokenSpin`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TokenSpin, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
